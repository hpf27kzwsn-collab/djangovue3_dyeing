## 范围与完成标准

P3 共 144 个 SQL 对象，其中 142 个非财务对象纳入本次，2 个独立财务对象继续暂缓。开发、历史数据对账、现场验收分开记账。具体状态及证据见 [142 项逐项记录](erp-phase3-review-20261016.json)，执行验证见 [核验结果](erp-phase3-verification-20261016.json)。

## 必须保留的差异和外部尾项

详细说明见 [异常文档 E120～E128](旧ERP复刻异常与合理实现说明.md)。主要差异包括：

- 最新库缺少旧坯料暂存表和针织日报落表，分别采用明确输入行与已有办理记录保存完整结果；没有新增另一套原表字段。
- 最新半成品库存已无旧数量/单位列，旧 `UpdateSemiStock` 按原单据单位映射长度或重量，原数量及候选来源留审计。
- 第四阶段已纠正此前遗漏：快照中存在 `fn_StuffPriceWeightedAverage`，现按最新结存＋其后指定入库类别的原加权公式实现，并撤换此前净流水替代算法；详见E121/E129。机物料旧分支未赋值的价格仍按 NULL 处理。
- 库存打印的旧日期列已不存在，按同一库存分组的最近记账日期提供筛选；坯料区域取同一库存分组实际流水关联的收料明细 Area。原字段不伪造，替代口径在异常文档列明。
- 原查重、超量、日期及外协不一致检查保留检查事实，能够录入的异常/重复数据不拒收。已有实际出库引用的入库删除仍遵守原依赖关系。
- 原过程的无序标量选择、排序规则、异常语法及变量未赋值等逐项列明；原始候选与业务事实不合并或删除。

SQL391 `sp_StuffWeightAutoStuffOut` 仍为部分完成。现有“按原称料规则生成领料”只能办理已明确的本地完成事件，不能代替外部 `WeighingSystem.dbo.WeighRecords` 与 `Textile_GXHFZD` 的四路自动取数及持续回传。缺少实际外部结构、完整事件和接入资料；该项继续列在 P3 尾项与 P7，不转成“仅待现场验收”。

## 历史对账与现场验收

本轮隔离测试覆盖正常收发、负数、重复条码/原键、多候选连接、细码余数、重办留档、删除/反审、8 类结转及价格回写。固定查询另有最新原字段结构执行验证。测试样例属于开发验证，不是从旧库取得的全量历史计算结果。

后续历史对账按单据原键和来源批次/提取行对应：先对原行及字段，再对收发流水、细码数量、工卡实配/完成状态、分组结存和统计结果。异常与重复独立列出，不净额抵消后声称一致。原自动流程的时间窗、旧期初和历史结转必须分开，避免把同一库存重复采用。

现场验收按业务链组合：采购申请/订单→分批收退→外协发收退/结案→库存及逆向→工卡实配/生产回写。重点确认单位、仓库/库位、货权、实际扫码/标签及调用时机。此文不会把 142 个 SQL 对象变成 142 个新增问题；先完成软件和对账准备，再汇总仍需现场确认的差异。

后续主顺序为 P4 生产执行、工艺、排程、称料和报工 → P5 质量/包装/交付及跨链撤销 → P6 旧客户端入口和自动调用时点 → P7 外部库及设备 → P8 完整历史与切换。P1 中控尾项、P3 外部称量尾项及历史/现场待办一直保留。

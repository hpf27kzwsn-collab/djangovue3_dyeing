# Post CRUD

将生成的 views.py / urls.py 放入对应应用，在 application/plugins.py 注册应用与路由。

如需使用系统的自动表单，将模型登记到 system/catalog.py 的 ENTITIES（键为 `post`），执行 init_data，再添加可见菜单。自动表单读取模型字段，不读取数据库专属 SQL。

ResourceViewSet 已包含 openpyxl xlsx 新增/更新模板、导入及同步/异步导出。业务列选择、保存后的明确动作和权限接入见 [Excel 实施记录与接入说明](H:/Project_python/django-vue3-admin/djangovue3/docs/Excel实施记录与接入说明.md)。

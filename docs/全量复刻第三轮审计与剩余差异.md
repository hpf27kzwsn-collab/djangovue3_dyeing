### S01 · P1 · 自定义菜单前缀与实际资源仍在页面路由中混用

**对照：** 原菜单的组件路径和组件名称分别表达加载组件与路由名称。当前批量生成按钮已允许选择实际资源，例如菜单前缀 audit-custom-post、接口资源 post；但 registerMenus 仍把 component_name 直接传给通用 Resource 的 entity。

**当前差异和影响：** 给该菜单设置 component=system/Resource，按钮生成返回 200，实际查询 API 为 /api/system/post/；页面却请求 /api/meta/audit-custom-post/，ENTITIES 查找抛 KeyError。初始化的默认菜单名称等于资源名，所以默认菜单验收未暴露此问题。

**核验级别：** 内存接口复现 + 前端调用链确认；没有冒称本轮浏览器复现。

**后续最小修正方向：** 明确菜单使用的资源标识，按钮生成和通用页面读取同一映射；保留独立的组件名称及权限前缀。不是遇到错误后退回首页。

### S02 · P1 · 子工作区新增父项详情权限依赖

**对照：** 原菜单按钮/字段工作区使用父页面传入的菜单记录，不为标题额外读取菜单详情。当前 updateContext 为显示父项标题，先 GET 父菜单或父记录，再刷新子表。

**当前差异和影响：** 普通角色只有 menu_button 查询授权时，子列表 GET 返回 200，但父菜单详情 GET 返回 403。api.ts 对任何 403 都跳转 /401；updateContext 的 await 也中断后续刷新。因此“有子表权限就能打开子表”未闭环。字典/其他带 parent 的上下文也需逐个核对这种额外依赖。

**核验级别：** 内存接口复现 menu_button 200 / menu detail 403；页面阻断由源码调用链确认。

**后续最小修正方向：** 沿父页面传递已有父项标题/记录，或把必要上下文并入子资源响应；不能为了显示标题要求角色额外获得整份父记录权限。

**源码定位：** [原父记录传入](H:/Project_python/django-vue3-admin/django-vue3-admin-master/web/src/views/system/menu/components/MenuButtonCom/index.vue:36)；[新上下文请求](H:/Project_python/django-vue3-admin/djangovue3/web/src/components/ResourceTable.vue:116)；[403 跳转](H:/Project_python/django-vue3-admin/djangovue3/web/src/api.ts:25)。

### S03 · P1 · 批量勾选按钮覆盖已有数据范围

**对照：** 当前新增的“选中当前按钮”调用 allButtons(true)，对可见范围内每个按钮都执行 toggleButton；toggleButton 无条件写入 data_range=3、dept=[]。

**核验级别：** 提取实际 Vue 函数体执行，确认 {data_range:4,dept:[9]} 变为 {data_range:3,dept:[]}；内存 API 保存同类请求后，原指定部门授权也变成全部/空部门。未在正式库保存授权。

**后续最小修正方向：** 批量选中只为尚未选中的按钮创建授权，保持已选按钮的数据范围和部门值。

### S04 · P2 · 多值查询的传输和类型转换未闭环

**对照：** 当前用户页主动增加了角色多选搜索；Axios 默认编码为 role[]=11&role[]=12，而后端只识别模型字段名或字段__lookup。原用户角色搜索是 disabled，并非已经存在同样可用的多选搜索。

**当前差异和影响：** 该新搜索请求返回 200，却忽略 role[]，连无关用户也返回。另一个有效查询 status__in=true,false，会先被 BooleanField 分支变成单个布尔值，再传给 __in，抛 TypeError。后者是当前通用查询新逻辑的问题，不声称旧项目所有 __in 查询都可用。

**核验级别：** 实际 Axios getUri + 内存 API 复现；布尔 __in 的异常为 bool object is not iterable。

**后续最小修正方向：** 前后端约定多值查询键和编码，按 lookup 及元素字段类型转换列表；按关联查询语义去重。

### S06 · P2 · 指定部门授权缺少原有可分配部门标记

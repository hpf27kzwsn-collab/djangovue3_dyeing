# 公开组件契约本机验收清册

2026-10-10。以当前组件实际发布的 props、emits、slots、公开方法为边界，逐项登记有限验收场景。证据是 `ninth-local-browser.json`，独立调用端是 `runtime/NinthContracts.vue`，普通调用端是组件示例和配置表单。没有把所有参数的笛卡尔积当成验收要求。

| 组件 | props 清册 | 实际动作与事件 | slots / 公开接口及边界 |
| --- | --- | --- | --- |
| Calendar | modelValue、multiple、range、pageTurn、crossPage、watermark、watermarkPosition、showPageTurn、selectable、validDate | 单选、多选、跨月保留/清除、指定范围、周日禁选、只读、隐藏翻页、九种水印位置；update:modelValue/change 实际输出 | cell-body 收到日期/选中态；data、onDataChange、reset、clear 与四个节日开关实际调用。范围不截断到 42 天。COMP18-calendar-*、MOBILE-10-calendar。 |
| FilePicker | modelValue、multiple、images、disabled、accept、inputType、types、selectable、showInput、valueKey、showUpload、showNetwork、inputSize、itemSize、inputClass、inputStyle、style、tabsType | 图片跨页多选、id 值、默认 URL 值、单选、音视频预览、本地上传、网络文件、禁用/只读、空列表；update:modelValue/change/save/close/closed 的调用输出有记录 | input、item、actionbar-left/right/bottom、empty 插槽实际显示，choose/preview/reload/confirm/remove/close 插槽回调实际操作；show、clear、onDataChange、data 已操作，open 是公开窗口状态。COMP18-file-*、MOBILE-10-filepicker、FILE-14。 |

以上是契约登记和指定场景的运行证据，不等于任意第三方调用、任意数据及所有浏览器均已验证。COMP-18 本轮从“缺完整清册”改为“清册完成、上述运行项已验证”；RemoteSelect 首帧文案、公开状态属性没有被冒充为另一个已操作方法，也不因此追加实现限制。

本机浏览器无法可靠产生原生中键 auxclick；Excel/WPS、移动真机、软键盘、系统休眠/唤醒、认证凭据更改及原生托盘，均按用户要求跳过。窗口宽度模拟不是这些场景的替代证据。

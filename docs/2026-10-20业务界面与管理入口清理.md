# 业务界面与管理入口清理（2026-10-20）

日常界面以染色业务为中心。“复刻”是开发范围要求，不作为产品宣传，也不要求业务人员了解来源表、核验规则和脚手架。此前直接展示平台菜单及开发核验信息不合适，本轮调整显示层。

## 调整结果

| 内容 | 当前处理 |
| --- | --- |
| 首页 | 染色业务工作台，8个常用资料快捷入口及基础信息、销售、采购、打样、生产、仓储、质量七模块 |
| 系统管理 | 账号、角色、权限及配置集中到右上角“管理设置”，继续遵守既有授权 |
| 任务管理 | 定时任务、运行记录等集中到“管理设置→运行维护”，不作为业务模块 |
| 组件示例、图表演示 | 退出业务菜单和菜单搜索；本轮未删除其文件或既有地址 |
| 数据维护 | 来源对应、导入核对、配置档案和用途尚未确定的资料保留在管理设置，默认折叠 |
| 日常名称 | 按已识别业务入口和基础资料分类显示，不再展示“完整旧业务资料”“待确认”等开发状态；通用字段显示编码、名称、创建人等中文 |
| 页面工具 | 普通业务页面保留导入、导出、录入、审核、转单、撤销等业务操作；来源配置、公式开发试算、初始化JSON和数据版打印集中到维护场景 |

名称来自现有资料目录、表单入口和基础资料分类；不根据表名猜测无法证明的业务含义。未知资料仍保留表标识供维护定位。没有修改字段键、来源主键、接口资源、保存服务和角色授权。界面收纳不构成新的权限隔离，后台仍按原授权校验。

## 核验

- 1152条既有菜单记录的地址、组件标识及父级数据保持不变，仅在前端展示时重新分组。
- 当前菜单快照对应757个业务页面、266个维护页面；两个演示入口退出导航，其余原可见页面无遗漏。这是导航数量，不代表这些页面的全部业务功能已经验收。
- 业务导航检查未出现“复刻、待确认、完整旧业务、旧ERP”等技术名称。
- 前端构建通过。保留现有大文件体积提示，未影响构建。
- 浏览器只读核验首页、管理设置及幅宽单位页。幅宽单位8条既有资料可读，中文字段、xlsx导入和添加入口正常；本轮没有提交表单、导入或删除记录。
- ERP前端8080、后端8001已刷新并返回成功；酒馆8000仍正常返回SillyTavern页面。

## 完成口径与后续

本轮界面调整的开发构建及上述浏览器检查完成。没有执行历史全量对账和现场验收；没有新增模型字段或额外旧erpID，也没有正式导入业务资料。异常、重复资料及其来源记录保留，未因菜单整理跳过。财务、打印和原35项查询继续暂缓；原有保存来源、事件时机、枚举绑定等差异仍按既有清单推进，冻结的933项盘点不重新计数。

后续页面仍按此原则：业务人员使用业务名称、业务字段和流程操作；维护人员通过管理设置查看技术来源和核验工具。不把来源证据缺失改写成已确认的业务含义。

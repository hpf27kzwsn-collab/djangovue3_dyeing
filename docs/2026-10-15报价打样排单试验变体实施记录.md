# 报价、打样排单及试验变体实施记录

日期：2026-10-15，第十五批。分支：`feature/erp-seven-module-models`。范围为销售报价、打样及试验业务，财务系统仍暂不开发。

## 本批已实现

### 销售报价

报价表头和明细页面增加“核对原报价函数及候选来源”，12个函数分别计算，不把不同版本合成一套假定规则。

| 原函数 | 实现的规则 |
|---|---|
| fn_GetColorNumPrice | 02成品收费、10位数字色号、原报价与最新调价；原程序没有客户/物料过滤，因此未增加 |
| fn_GetPriceListVat | 最新及第二条调价、订单日期/出库日期分支、20公斤小缸区间逐行加价 |
| fn_GetPriceUnit | 01坯布/其他成品数量、80公斤分界、RC07区分、客户及20位数字色号报价单位 |
| fn_ColorNum_BasicsPrice | 用量下开上闭、成本上限、最低价；0/NULL价转成本下闭上开分支，再除1000 |
| fn_GetPackPrice、fn_GetPackQtyPrice | 两者都直接读取工序Price，并不擅自按函数名称增加数量计算 |
| fn_GetDyePrice | 原函数实际读取染色曲线MaxValue，保持原实现 |
| fn_GetPriceRemark | 原色号提取数字后与原传入文本比较，逐行拼接、NULL重置及100字节返回 |
| fn_GetJObSheetNoAttePrice、fn_GetJObSheetNoAttePriceUnit | 客户基础另收费优先，其次客户空物料、通用空物料；原未赋值ProdID分支不补造参数 |
| fn_NewGetDyePrice | 基础套价＋实际额外工艺－套价已含但工卡未用工艺＋荧光＋等级＋小缸；ZN指定工艺免价；Kind 0～8分别返回 |
| fn_GetTechPrice | 出库单位4、05类附加工艺，客户价优先，通用价其次；重复连接全部累计 |

服务：`source_quote_functions.py`、`source_quote_components.py`。返回计算值、分量、所有实际取价候选及原记录ID/旧erpID。报价查询本身不生成或修改报价单，也不生成财务凭证。

### 打样规则与排单

- `Sp_DyeDipsRecord`、1、2、10、22、EmpID六个过程分别提供预览、采用及撤回。
- 新旧色深阈值分别保留。现代版本保留A～F各列成本合计取最大；染程名称保持原XML拼接转义。色号资料及客样颜色按原ColorNum、ColorNo先后连接回写。
- 高牢度原查询没有当前流水限制，因此预览及执行包含实际跨单目标；不悄悄缩小范围。原全库变体提供`original`范围，另提供明确的所选流水范围`selected`。主过程本身始终按原流水参数。
- 10版保留染程计数、双染0/1及特殊色深2，前段客样色深更新照做；其没有其他版本末尾两次客样同步，未擅自添加。
- EmpID版按四个槽位的非空数分摊；同一人填两个槽位仍算两个。无人员的原除零差异单列E79。
- 客样颜色页面新增排单来源预览，以及普通打样/复版排单。实际复制颜色与最新打样模型共有字段，并承接来样表头的经营单位、客户、销售组、销售员及两种对色光源；办理人明确填写版本、人员、班组及时间。
- 沿用两种原入口的号码规则、部门和字段默认值；新单没有凭空生成旧erpID。来源颜色、全部表头候选、原选择器可见性和已有打样记录留在办理事实中。

服务：`source_sample_variants.py`、`source_sample_schedule.py`。回写和撤回在事务内执行；撤回恢复实际改动字段，已有下游改动按业务次序先撤回。

### 质量试验

全部保留并验证以下七种原入口：加色产量登记、全部试验、色牢度、PH、缩水、强力、水质。原Value字段、物料及比较物料照存，异常原值不因不符合常见格式而被删除。

`ProdTest_AddColorProduct`的AfterSave钩子已接入真实保存流程：

1. 按试验流水查找7类原行，连接02工位班组及人员，保留全部候选。
2. Value40非空的候选按原映射生成WProcess、JobShiftEmp、WProcessStep。GX41对应67/933/加色，其他对应68/934/返加色；Value39为机台，Value40为前染程。
3. 原报工及人员/步骤替换留档，退出活动统计；原删除触发回写按既有服务执行。保存修改时先撤回上次生成，再生成本次结果。
4. 页面另提供预览、明确生成及撤回，供历史试验或其他入口接续使用。撤回恢复原活动记录及实际回写，新生成行也留档。存在后续替换或字段变化时按实际业务依赖逆向，不能覆盖后续业务。

服务：`source_trial_variants.py`；保存接入`source_services.write`，活动范围接入`source_execution_state`。试验主记录、被替换记录、新生成记录均有来源事实。
